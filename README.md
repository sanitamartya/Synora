# Synora

Synora is a backend engineering project built to learn and implement professional backend architecture.

## Tech Stack

- Node.js
- Express.js

## Current Architecture

- Application Routes
- API Entry Point
- Controllers
- Services
- Repositories
- Shared Utilities
- Middleware
- Logger

## Run

```bash
npm install
npm run dev
```

Project documentation is available in the `docs/` directory.
